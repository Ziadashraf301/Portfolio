## 🚀 Modern React Portfolio

This repository now contains a modern, single-page React application built with **Vite**. The design has been entirely revamped with a premium dark-mode aesthetic (glassmorphism, smooth animations) focusing heavily on **AI, Data Science, and MLOps**, while maintaining key highlights of **Data Engineering and Business Intelligence**.

### 🛠️ Tech Stack
- **Framework**: React 18 + Vite
- **Routing**: React Router v6
- **Styling**: Vanilla CSS with CSS Variables for theme consistency
- **Icons**: Lucide React

---

## 💻 Local Development

To run this portfolio locally on your machine, follow these steps:

1. **Install Dependencies**:
   Open a terminal in this directory and run:
   ```bash
   npm install
   ```
2. **Start the Development Server**:
   ```bash
   npm run dev
   ```
3. Open your browser and navigate to `http://localhost:5173/`

---

## 🌐 How to Deploy to GitHub Pages

Deploying your new React application to your existing GitHub Pages URL is very straightforward.

1. First, ensure you have committed all your changes (if you haven't already).
2. The `package.json` has been pre-configured with the `gh-pages` module and a deploy script.
3. Simply run the following command in your terminal:
   ```bash
   npm run deploy
   ```
   *This script will automatically build your React app and push the bundled files to the `gh-pages` branch, updating your live portfolio instantly.*

4. **Note**: If you want to clean up the repository, you can safely delete the old HTML files (`Airline_tweets.html`, `Credit_Card_Dashboard.html`, etc.) as their functionality has been embedded into the React app.
